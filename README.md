# Email Classification Using DistilBERT

An NLP project that uses DistilBERT and Hugging Face Transformers for email text classification.

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- DistilBERT
- Pandas
- Scikit-learn
- Google Colab

## Project Overview

This project demonstrates transformer-based text classification using DistilBERT.

The email text is preprocessed and tokenized using a DistilBERT tokenizer, and the pretrained transformer model is used for sequence classification.

## Workflow

1. Load the email dataset
2. Preprocess the text data
3. Tokenize text using DistilBERT tokenizer
4. Prepare training and validation data
5. Train/fine-tune the classification model
6. Evaluate model performance
7. Predict the class of new email text
